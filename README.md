# 予約チェック

**予約が重なってから謝る前に。登録時にダブルブッキングを防ぐ**

登録時にダブルブッキングを知らせる、個人事業主向けの予約確認ツールです。

## 解決する困りごと

サロン・教室・訪問サービスを一人で回していると、予約は電話・DM・メールと別々の経路から入ってきます。
どこにも一本の台帳がないので、同じ時間帯に二重で受けてしまい、**登録したあとで気づいて謝ることになる**。

この道具は、登録ボタンを押す前に重なりを知らせます。

## できること

- 顧客名・メニュー・開始日時・終了日時・メモを登録する
- 時刻を入れた時点で、既存の予約と重なっていれば警告する（押す前に分かる）
- 重なっている相手（誰の・何の予約か）、被っている時間帯と長さ、**次に空く時刻**を表示する
- 重なっている間は登録できない
- その日の時間の埋まり具合を横帯で表示する。上段が予約済み、下段が入力中、
  重なっている区間だけ赤い斜線で縦に貫く（あと何分ずらせば入るかが図で分かる）
- 予約をキャンセルする。記録は消さずに「キャンセル済み」として残す
- キャンセルした枠は空きとして扱う。戻すときは改めて重なりを確認する
- 予約の内容を、そのまま返信に貼れる形でコピーする
- 入力内容はブラウザの中だけに保存する（どこにも送信しない）

## 使い方

```bash
npm install
npm run dev      # 開発サーバー
npm run check    # 重なり判定の境界条件を検証（23件）
npm run build    # 型検査＋本番ビルド（docs/ に出力）
npm run lint     # 静的解析
```

## 重なりの判定について

予約は **半開区間 [開始, 終了)** として扱います。終了時刻ちょうどは「もう空いている」。

つまり 10:00〜11:00 と 11:00〜12:00 は**重なりません**。これは連続して受けたい隣接予約であって、
ここを弾いてしまうと道具として使えなくなるためです。1分でも食い込めば重なりと判定します。

判定は画面を通さずに検証できるようにしてあります（`src/utils/overlap.ts` はブラウザの機能に触れない純粋な計算のみ）。
`npm run check` で以下を含む23件を確認します。

- 完全に重なる / 一部だけ重なる / 包み込む・包まれる
- 前後が隣接する（重ならないこと）
- 1分だけ食い込む（重なること）
- キャンセル済みを除外すること
- 日をまたぐ予約、月またぎ・年またぎ
- 終了時刻が開始時刻より前、開始と終了が同じ、1件の上限（ちょうど7日は通し、7日と1分は弾く）
- 存在しない日付（2月30日、閏年でない年の2月29日）

## 構成

```
src/
  types/reservation.ts        予約の型と上限値
  utils/overlap.ts            重なり判定・日時の解釈・入力検証（画面に依存しない）
  utils/storage.ts            保存と読み込み（壊れた値を捨てる）
  components/
    ReservationForm.tsx       入力フォーム
    DayTimeline.tsx           その日の時間帯を横帯で見せる
    OverlapNotice.tsx         重なりの詳細（この1箇所だけに出す）
    ReservationList.tsx       予約一覧（日付ごと）
    Icon.tsx                  状態を表す絵（色だけに頼らないため）
  App.tsx                     画面全体の組み立てと状態
scripts/check-overlap.ts      重なり判定の検証
```

## 使用技術

React 19 / TypeScript / CSS / localStorage / Vite

外部の部品は使っていません（アイコンも含めて自前）。
